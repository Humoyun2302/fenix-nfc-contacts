# Fenix NFC — Contacts

Mobile-first multilink / link-in-bio page for Fenix NFC contacts.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Live

https://fenix-nfc-contacts.netlify.app

## Deploy

Deployed on Netlify with continuous deployment from GitHub (`main`).
